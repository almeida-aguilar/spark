# Linterna LED

## Construcción
Sigue estos pasos para armar tu linterna con LEGO WeDo 2.0.

1. **Paso 1:** Coloca el hub WeDo 2.0 sobre una base estable.  
   ![Hub sobre la base](images/linterna-led/paso-1.webp)
2. **Paso 2:** Verifica que el hub esté encendido y con batería.

## Programación en Spark
Recrea este programa en el editor para controlar la luz.

![Programa de la linterna LED](images/linterna-led/codigo.webp)

**Bloques principales:**
- `al presionar el botón del hub` — inicia la acción cuando pulsas el botón.
- `fijar color de la luz a [COLOR]` — enciende el LED con el color elegido.
- `apagar luz` — apaga el LED.

## Cómo probarlo
1. Conecta el hub WeDo 2.0 desde Spark.
2. Ejecuta el programa (bandera verde).
3. Presiona el botón del hub para ver cómo cambia la luz.
